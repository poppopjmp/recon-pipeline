# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

recon-pipeline is supported on actively-maintained Python releases (3.9+).

## Reporting a Vulnerability

Please report security issues privately via GitHub's
["Report a vulnerability"](https://github.com/poppopjmp/recon-pipeline/security/advisories/new)
feature rather than opening a public issue.

Include enough detail to reproduce the problem (affected version, Python
version, OS, and steps). We will acknowledge the report and work with you on a
fix and coordinated disclosure.

## Scope and Intended Use

recon-pipeline is offensive-security tooling intended for **authorized**
testing only — your own assets, engagements you are contracted for, or targets
that are explicitly in scope (e.g. a bug-bounty program). Always operate within
the law and the target's rules of engagement.
